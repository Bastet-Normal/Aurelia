# Aurelia · 黄金决策工具

Aurelia 是一个典雅风格的黄金市场分析与分批购买辅助工具前端原型。

## 运行

这是一个零依赖静态页面，直接打开 `index.html` 即可预览。也可以在当前目录运行：

```bash
python -m http.server 4173
```

然后访问 `http://localhost:4173`。

## 当前功能

- 市场总览：现价、涨跌幅、市场状态
- 影响因子：美元指数、实际利率、ETF 持仓、黄金波动率
- 趋势预测：价格中位预测与置信区间视觉化
- 信号评分：综合评分和重新计算反馈
- 购买计划：预算、持有周期、风险偏好与三批配置金额
- 导航定位、Toast 反馈、日期自动更新
- 预算与风险偏好通过 `localStorage` 保存在本地

## 数据说明

页面当前使用演示数据。接入真实行情时，建议把 `app.js` 中的演示数值替换为统一的数据层，并明确标注数据源、更新时间、币种、单位和延迟状态。预测结果应显示区间与置信度，不应被表述为确定性投资建议。

本地 API 配置请放在 `.env.local`，该文件已加入 `.gitignore`，不会上传到 GitHub。不要把 API Key 写入 `index.html` 或 `app.js`，因为静态前端会将密钥暴露给所有访问者。
