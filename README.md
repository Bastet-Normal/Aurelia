# Aurelia · 黄金市场工作台

一个面向中文用户的黄金工作台，可查看人民币克价、比较渠道报价、安排分批预算并记录实际买入。支持 GitHub Pages。

世界黄金协会的[中国黄金市场季报](https://china.gold.org/goldhub/research/gold-demand-trends/gold-demand-trends-china-focus-q3-2026)显示，2026 年第三季度国内金条金币需求达 79 吨，同比增长 7%，金饰消费量同比下降 22%。[上海黄金交易所](https://www.sge.com.cn/sjzx/jzj)公布上海金基准价，[银行积存金条款](https://media.icbc.com.cn/agreement/906030060782604296.html)列明了赎回报价和手续费规则。产品据此优先提供人民币走势、国内基准入口和渠道含费比价。本项目尚无实际用户使用数据。

## 运行

```sh
python3 -m http.server 4173
```

访问 `http://localhost:4173`。支持 `#/overview`、`#/analysis`、`#/compare` 和 `#/plan` 深链接。旧的 `#/plan/compare` 仍可打开比价。首次联网完成 Service Worker 缓存后，断网时可继续打开页面，查看已缓存的数据及计划。支持安装的浏览器也可将工作台添加到主屏幕或程序坞。

## 数据及更新

| 数据 | 来源 | 刷新 |
| --- | --- | --- |
| XAU/USD 现货参考报价 | [Gold API](https://gold-api.com/docs) | 页面可见时每分钟检查，显示数据源时间 |
| XAU/USD 日度参考序列 | [波兰央行](https://nbp.pl/en/statistic-and-financial-reporting/rates/) · [Frankfurter NBP.A](https://frankfurter.dev/) | 缓存四小时，保存最近约三年观测 |
| USD/CNY 最新及历史参考汇率 | [欧洲央行](https://www.ecb.europa.eu/stats/policy_and_exchange_rates/euro_reference_exchange_rates/html/index.en.html) · [Frankfurter](https://frankfurter.dev/) | 缓存四小时，显示汇率日期 |

服务无需 API 密钥。报价过期会标出时间，失败时保留最近一次有效缓存，或显示可用的日度参考价。首页人民币报价使用同日或此前七天内最近的参考汇率。走势图可选 30、90、252 个观测日。人民币历史价仅用同日汇率换算，缺少汇率的日期略过。页面同时提供上海金基准价官方入口。首次访问遇到数据源故障时，页面显示等待或不可用状态，计划仍可使用。

## 市场分析

可切换美元与人民币口径。5、10、22 日按各自参考序列的观测日计算。每个期限取最新 252 个同期限简单收益，使用第 10、50、90 分位乘以最新日度参考价。区间描述期限终点，图中的连接线用于示意。

滚动检验按期限间隔取样，每个检验点仅用当时已发布的数据。页面先展示历史命中次数及比例，计算方法里保留平均绝对百分比误差和假设价格持平时的误差。历史覆盖率仅描述历史样本。

## 购买计划

计划保存到当前浏览器，可新建、编辑和删除。预算下方即时显示各批金额。日期为当地日历日期，持有周期决定预设的复盘间隔。

分批金额按整元分配，合计等于预算。克数和费用按「黄金净额 = (批次预算 − 该批固定费) ÷ (1 + 买入费率)」估算。固定费用在每批预算内扣除。可使用市场参考价，或从比价带入实际报价与费用，再按各批收费情况调整。

保存计划后，可为每批登记一笔实际买入汇总，包括日期、含费实付金额和克数。进度显示累计克数、实际平均克价、剩余预算或超支。CSV 与 JSON 备份包含记录。更新时会把旧计划迁移到独立存储区。旧版 JSON 也可导入，原计划与日期保留，购买记录初始为空。

日历导出生成三个全天事件，对应计划起点与两次复盘。将 `.ics` 导入系统日历即可查看。

## 渠道报价比较

输入同等纯度和相同克重的渠道实际报价。买入总价由单价、克重、额外买入费率和整笔固定费用计算。填入回购报价和费率后可查看回购净额、估算盈亏和回购保本价。「用此报价做计划」会将对应的买入单价与费用带入计划试算。从已有计划出发时会创建新计划草稿。

## 验证与部署

```sh
node --test
```

推送 `main` 触发 GitHub Pages 工作流。工作流检查语法和数据逻辑，只打包站点所需文件。发布时同步更新 HTML 中的资源版本、`sw.js` 缓存名称和缓存资源列表。
